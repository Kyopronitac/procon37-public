# 開発者への依頼

初期の各並列候補および各世代の開発者に、実値を埋めて渡す。初期構築では単独首位の条件を課さず、15スレッド以内で動く候補を完成させて親へ返す。世代育成では以下の単独首位条件を使う。

```text
対象{solver ID}を、保存された最強単一スレッドの共通基準から再構築してください。
ゼロから作る必要はありません。共通基準のソース・資料は参照できます。
並列化だけでなく、アルゴリズムの改変・置き換えも許可します。
多様な強い4体を育てるため、設計・実装・改善方法はあなたに任せます。

作業ルート・編集範囲: {対象候補の絶対パスと所有範囲}
共通基準の読み取り場所・識別情報: {独立した基準版のパス・ハッシュ}
公開仕様・適用規則: {必要なREADME・AGENTS.md・JSON Lines仕様のパス}
対象のホスト・チーム番号・CPU集合: {固定された実値}
ビルド・起動方法: {コマンド・ランチャー・ソルバ設定の実値}
対戦相手: {固定の他3並列＋S0（第6世代）・S1（第8世代）のIDと起動情報}
読み取り対象外: {旧並列実装、他候補のソース・設計履歴、親の管理記録、保護領域}
実行手順: {このスキルのdocs/runtime.mdの絶対パス}

ソルバ内部は制御を含めて最大15スレッドです。制御1＋探索14などで構成し、
ライブラリが生成するスレッドも上限に含めてください。CPU集合の設定だけで
スレッド数を制限したとみなさず、実行時に確認してください。

旧対象の並列実装や他候補の設計は引き継ぎません。相手はブラックボックスで、
コピーやGit履歴を含む実装閲覧・検索・逆解析は禁止です。共通基準は明示された
参照可能な例外です。tester/game/samplesとsolver/docs/solver-pool-experimentの
実装は保護されています。成績・リプレイ・公開通信仕様は利用できます。

正式評価はこのPCのserverによる6体対戦12件（seed 0〜11、形式自動、
既定制限時間、既定の練習場設定、.server/runsへの保存）です。
全12試合で6体全員AC、候補の平均順位が他5体すべてより厳密に小さくなるまで
改善してください。同率首位は未達です。60件の追加評価は不要です。

開発中の単独テストと6体での短縮対戦は、あなたが起動・監視・集計します。
件数・seed・制限時間・探索予算・試行回数を自由に選び、
事前確認なしで実行できます。フルテスト以外は一時保存先を使ってください。
指定3台に対するSSH関連操作はすべて事前許可済みで、必要な接続・転送・
環境構築・実行に改めてユーザーの確認は不要です。固定相手は変更せず、
親の正式評価に干渉する実験・ビルドを重ねないでください。
自分の対象ソルバのバイナリと専用ランチャー・起動設定は、あなたが
リモート配置してよいです。配置前後のパス・ソースとバイナリのハッシュ・
起動設定を記録し、親へ報告してください。他5体、共通環境、固定ホスト・
チーム番号・CPU割り当ては変更せず、配置後に6体の短縮対戦を実行してください。
短縮テスト全体の順位合計で候補が1位になるまで改善を続け、1試合だけの
1位で判定しないでください。短縮結果は正式評価・昇格の根拠にはしません。

短縮テスト全体で1位を確認したら編集を止め、変更範囲・方針・ビルドと起動設定・スレッド数・
全6体の判定・順位合計、短縮結果の保存先・候補の識別情報を親へ報告してください。
親はフルテスト・共通環境や他枠の配置変更・昇格判断を担当し、短縮対戦を代行しません。
評価中は候補を変更せず、未達なら親の結果を受けて改善を続けてください。
自分の対象枠以外の配置管理、固定相手・server・bridge・採点器・対戦設定の変更、commit・pushは
開発作業に含めません。
```
