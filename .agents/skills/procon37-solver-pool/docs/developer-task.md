# 開発者への依頼

必要な実値を埋め、`fork_turns="none"` の開発subagentへ渡す。

```text
第{世代}世代のsolverを新規設計し、固定4体とのgameフルテストで
平均順位が単独首位になるまで改善してください。同率首位は未達です。
設計・実装・実験方法はあなたに任せます。

作業ルート・編集範囲: {絶対パスと対象solverの所有範囲}
公開仕様・適用規則: {必要なREADME、AGENTS.md、通信仕様等のパス}
ビルド・実行・固定対戦設定: {コマンドまたは設定ファイル}
正式評価条件: {ルートREADMEに従う件数・seed・制限時間・実行条件}
テスト操作: {procon37-tester/SKILL.mdのパス}
読み取り対象外: {sample、旧実装・旧設計資料、親の世代管理資料のパス}

旧対象は削除済みです。公開仕様から独立して開発してください。
相手はブラックボックスで、コピーやGit履歴を含む実装閲覧・検索・逆解析は禁止です。
ビルド・実行・成績・リプレイは利用できます。

開発中の短縮テストは自由です。件数・seed・制限時間・探索予算・試行回数を
自分で選び、事前確認なしで繰り返してください。
親が昇格用の正式評価を担当します。候補ができたら編集を止め、変更範囲・
方針・実行条件・実験結果の要点を提出し、未達なら親の結果を受けて改善を続けてください。
正式評価中は候補を変更せず、評価に干渉する実験を避けてください。

sample配置・対戦設定・採点器の変更、commit・pushは親の担当です。
```
