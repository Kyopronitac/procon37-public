## 競技サーバーとの通信で参照する主な記述

| 内容 | 資料 |
| --- | --- |
| 試合開始と同時に問題データが取得可能になり、規定時間内にタイプ選択を受け付ける | 本選マップに関するお知らせ「試合の進行について」 |
| タイプ選択時間は1回戦・敗者復活戦60秒、準決勝90秒、決勝120秒。行動回答時間は各60秒 | 本選マップに関するお知らせ |
| 予行演習の制限時間は本選より短くなることがある | 本選実施要項 3.2 |
| HTTP/1.1のみ対応 | 問い合わせと回答その2 A41 |
| リクエストは秒間5回ほどを目安にする | 問い合わせと回答その2 A42 |
| サーバーの時計はNICTのNTPで同期している | 問い合わせと回答その2 A57 |
| 競技ネットワークは有線LAN。Wi-Fiによる通信は認めない | 募集要項「通信方法」「注意事項」 |
