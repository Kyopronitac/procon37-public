# C014-SHARE100MS

C013 を基に `cross_elite.rs` の `ELITE_INTERVAL` だけを 500 ms から 100 ms に変更した候補です。C013 の保存版は変更していません。採用・対戦評価は未実施です。

この定数は PC 間の送信間隔、各探索スレッドから共有バスへの公開間隔、共有バスの接続・送信・公開時に必要な残り時間にも共用されています。この候補ではこれらが一緒に変更されます。受信確認間隔 `CHECK_INTERVAL=250ms`、停滞条件、修復処理、探索方式、日中提出時刻、wire VERSION=4、77 探索 + 3 集約の構成は C013 と同じです。

ソース識別と親との差分は `source-manifest.json`、実行ファイル・検証結果は `validation.json` に記録します。既存の単体・TCP テストのソースも変更していません。
