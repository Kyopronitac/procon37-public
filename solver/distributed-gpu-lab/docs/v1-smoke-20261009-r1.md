CPU heap参照は0.601/1.265/2.379 msだったが、C008の共有builderそのものではなく、CPU側のscalar作成・検証費用もその値に含まない。ここから対戦性能の優劣は判定しない。初期化の2.71秒は小さい要求を多数並べても容易に償却できないため、ソルバが実際に必要とする表数・target数を使い、CPU共有後の構築量と、初期化を先行できる寿命を測ってから統合を判断する。今回の検証を理由にGPUを採用しない。
