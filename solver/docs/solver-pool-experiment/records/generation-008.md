# 第8世代の登録記録

2026年10月07日14:09 JST、最良記録と同率の現採用候補v117を第8世代として登録しました。停止指示前の実行・予約済みテストはすべて終了し、結果回収を完了しました。実装は変更せず保存し、新規開発・追加評価・次世代への移行を停止しています。

## この世代の生成方法

**第8世代は、従来の `procon37-solver-pool` の世代育成手順によって生成されたものではありません。**

従来の手順は、5体のうち平均順位が最下位のソルバを削除し、旧実装を引き継がない開発者がゼロから新規設計したソルバを評価・昇格する方式です。今回の第8世代は、第7世代の実装を引き継いで継続改善し、その過程で作成済みの候補から、gameの既定フル30件で最良の成績を記録した実装を選び、ユーザーの明示指示により第8世代として登録したものです。最下位の削除、新規設計の開発者起動、従来方式の配置替えは行っていません。

世代番号はこの改善版の識別のために付けるものです。従来のsolver-pool方式を1世代実施したという記録にはせず、第7世代からの派生として扱います。対戦相手は固定された第2・第6・第4・第3世代で、相手の内部実装を参照せずに開発・評価しました。

開発終了後、ユーザーから `solver-pool-experiment` への立ち入りを、第8世代の登録・配置変更のために許可されています。この許可は登録に必要な保存構成の確認に使い、過去世代の内部実装をソルバ開発・改善へ流用しません。既存の保存版は第1〜5世代の歴史的なスナップショットで、現在の対戦配置とは独立しています。

## 選定結果

既定フル30件の平均順位を優先し、同率なら1位件数、それも同じ場合は既存の採用版を維持する基準で選びました。v117とv123はともに順位合計43・平均1.433333位・1位24件で同率です。このため現採用のv117を維持しました。v154とv170も順位合計43ですが、1位件数はそれぞれ21件・20件でした。選定対象の31件のフル評価集計と全候補の結果は [機械可読記録](generation-008.json) に保存しています。

**当初の「全30件1位・平均1.00位」という目標は未達です。** 第8世代への登録は、ユーザーの終了・登録指示に基づくもので、元の目標を達成したという意味ではありません。goalは一時停止状態を維持します。
