# 実行設定：第2世代

[アルゴリズム](algorithm.md) / [検証記録](validation.md) / [世代記録](../records/generation-002.md)

保存対象は sample1 に配置された第2世代のソルバ。正式評価は対戦テスタ `game` で実施された。

| 項目 | 条件 |
| --- | --- |
| 問題 | 30件、seed 0〜29、形式自動選択 |
| 制限時間 | テスタ既定値 |
| 探索seed | 起動引数 `0` |
| 並列実行 | 6試合 |
| ソルバ内部 | 単一スレッド |
| 相手構成 | [第2世代の設定](../records/generation-002-config.json) |

当時の設定JSONには実行環境の絶対パスが含まれる。現在の環境で再実行する場合は [再現手順](../reproduction.md)に従ってパスを置き換える。実時間打切りとCPU負荷により、同じseedでも得点が一致するとは限らない。

## 実装上の探索時間

日別探索は要求時間の90%または52秒の短い方を使う。車種選択は要求時間の80%を候補数と日数に配分し、90%に達すると新たな候補を始めない。
