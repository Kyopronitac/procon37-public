# ソルバの保存版と世代別記録

このディレクトリには、第1〜8世代の実装保存版と、評価・昇格・登録の記録をまとめています。各世代は単一ファイルの `solver0x.rs`、元の分割ソースを保持する `solver0x/`、説明資料の `README.md`・`algorithm.md`・`settings.md`・`validation.md` で構成します。世代別の原記録は [records/](records/README.md) を参照してください。

第1〜7世代は従来のsolver-pool方式による独立した新規設計・評価・昇格の世代です。**第8世代は従来のsolver-pool方式で生成した世代ではありません。** 第7世代の継続改善から最良記録と同率の現採用v117を選んで登録した派生世代です。最下位削除・ゼロからの新規開発・従来方式の配置替えは実施していません。[第8世代の記録](records/generation-008.md)に生成方法・before / after・最終成績を記載しています。

第1〜7世代の値は正式昇格判定、第8世代は既存候補からの採用判断に使った最良観測記録です。各runは30件・seed 0〜29・形式自動・既定制限時間で5体全員ACでした。相手の配置と実装が世代ごとに異なるため、順位合計を直接比較して強さの順を付けることはできません。各runの順位・得点・実行条件は [世代別記録](records/README.md) に保持しています。

第8世代の最良観測記録は平均1.433333位・1位24件、改善開始時との公式比較は19勝3同点8敗でした。平均1.00位の目標は未達です。実時間制探索と対戦の変動があるため、再実行で同一成績を保証しません。

## 保存形式と照合

元の分割ファイルは `solver01/`〜`solver08/` に保持し、外部モジュールをインライン化してRustfmtで整形した `solver01.rs`〜`solver08.rs` をCargoのビルド対象としています。出典・元ファイルのSHA-256・単一ファイル版のSHA-256・変換内容は [source-manifest.json](source-manifest.json) に記録しています。

第1〜5世代の保存ソースと既存の検証結果は保持しています。第6・7世代は正式昇格コミットから、第8世代は評価済みv117から元の分割ソースを保存しました。第6〜8世代の単一ファイル化と資料の整理では追加ビルド・追加テストを行わず、元ソースのハッシュ一致と変換・参照の静的確認を実施しました。[保存方法と照合](consolidation.md)を参照してください。

2026年10月07日に旧 `solver/docs/pool/` の全記録を内容を保持して [records/](records/README.md) へ移管し、旧ディレクトリを削除しました。保存版は現在の対戦テスタの既定配置とは独立しており、保存形式の統一も対戦配置の変更を伴いません。
