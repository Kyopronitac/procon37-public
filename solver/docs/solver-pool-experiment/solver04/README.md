第4世代で独立に設計したソルバ。巡回経路と補給の共同計画、翌日の見通しを使う。ソースは現在の対戦相手slot3にあり、コミット `11d1e19` に保存されている。専用モジュール9ファイルは `tester/game/samples/src/pool-generation-004/` にある。設計要素の詳細と候補間比較は世代記録を参照。

正式評価run `1790600156388062978-4` は30件すべて5体AC。順位合計は対象59、相手78・112・127・60で単独首位。対象得点合計は種類542・日別種類3588・玉数7462。候補1・2は正式条件を満たさず、候補3で昇格した。

この説明は当時の開発記録と保存した実装に基づく。

単一ファイル版は [solver04.rs](../solver04.rs)。元の入口は [entry.rs](entry.rs)、依存モジュールもこのディレクトリに無改変で保存した。
