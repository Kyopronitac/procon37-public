# Poolソルバ保存版の保護

このディレクトリには対戦相手として使うソルバの実装と資料を保存している。
他の作業では、配下のソース・資料・設定・マニフェストを閲覧しない。内容検索、Git履歴からの復元、別名のコピーの参照、バイナリ逆解析も禁止する。全体検索や資料作成でもこのディレクトリを除外し、内容を外部の文書へ転載しない。

ビルド・実行・公開通信仕様・成績・リプレイの確認、および識別用ハッシュ計算は可能。
ユーザーがこの保存版自体の作成・修正・調査を明示的に依頼した場合のみ、その作業に必要な範囲で閲覧・編集できる。この例外を対象ソルバの開発・評価に利用しない。

これはエージェント向けの作業規約であり、アクセス権限による強制隔離ではない。
