# 実行設定：第3世代

[アルゴリズム](algorithm.md) / [検証記録](validation.md) / [世代記録](../records/generation-003.md)

保存対象は sample4 に配置された第3世代のソルバ。正式評価は対戦テスタ `game` で実施された。

| 項目 | 条件 |
| --- | --- |
| 問題 | 30件、seed 0〜29、形式自動選択 |
| 制限時間 | テスタ既定値 |
| 探索seed | 起動引数 `0` |
| 並列実行 | 6試合 |
| ソルバ内部 | 単一スレッド |
| 相手構成 | [第3世代の設定](../records/generation-003-config.json) |

当時の設定JSONには実行環境の絶対パスが含まれる。現在の環境で再実行する場合は [再現手順](../reproduction.md)に従ってパスを置き換える。実時間打切りとCPU負荷により、同じseedでも得点が一致するとは限らない。

## 実装上の探索時間

車種選択は、5台以下かつ要求時間8秒以上なら2日試走を使う。そうでない場合は候補あたり最大6秒程度に制限する。日別探索の上限は `RENDEZVOUS_MS` で変更できる。未指定時は要求時間の90%を使い、どちらの場合も要求時間から250 msを残す。先読み時は候補生成と翌日評価に時間を分ける。
