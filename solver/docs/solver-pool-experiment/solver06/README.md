公開通信仕様と共通エンジンから新規設計した正式昇格版です。経路表、補給時刻、巡回計画を組み合わせ、当日と翌日の探索を行います。 従来のsolver-pool方式による独立した新規開発・評価・昇格の世代です。`main.rs` がJSON Linesの入出力を、`solver/planner.rs` が探索と提出前の検証を担当します。

正式評価run `1791150449580370511-14915` は30件すべて5体AC、警告0。対象の順位合計は64、平均順位は2.133333位で単独首位でした。対象の種類・日別種類・玉数の合計は543/3680/8392です。詳細は [検証記録](validation.md) に記載しています。

昇格コミット `a9216446bd0ae6837689a0847bb3f467c2d1d428` から元の2ファイルを変更せず保存しました。単一ファイルの [solver06.rs](../solver06.rs) は、この2ファイルのモジュールをインライン化し、Rustfmtで整形した記録です。Cargoのビルド対象は `pool-solver-06`。出典・SHA-256・変換内容は [ソース対応表](../source-manifest.json) を参照してください。

保存形式の整理では追加ビルド・追加テストを行っていません。成績は保存元の評価によるものです。
