## 保存形式の照合

昇格コミット `a9216446bd0ae6837689a0847bb3f467c2d1d428` の [main.rs](main.rs) と [solver/planner.rs](solver/planner.rs) をバイト同一で保持しています。[solver06.rs](../solver06.rs) は外部モジュールを同名のインラインモジュールへ展開し、Rustfmtで整形した保存用の単一ファイル版です。出典のSHA-256と変換後のSHA-256は [ソース対応表](../source-manifest.json) に記録しています。

今回の整理では追加ビルド・追加テストを実施していません。検証根拠は保存元の既存評価、元の分割ソースのハッシュ一致、変換・Cargo設定・資料参照の静的確認です。単一ファイル版での再評価結果として扱わず、実時間制探索による成績の変動も考慮してください。
