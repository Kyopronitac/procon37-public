# 実行設定：第1世代

[アルゴリズム](algorithm.md) / [検証記録](validation.md) / [世代記録](../records/generation-001.md)

保存対象は sample2 に配置された第1世代のソルバ。正式評価は対戦テスタ `game` で実施された。

| 項目 | 条件 |
| --- | --- |
| 問題 | 30件、seed 0〜29、形式自動選択 |
| 制限時間 | テスタ既定値 |
| 探索seed | 起動引数 `0` |
| 並列実行 | 6試合 |
| ソルバ内部 | 単一スレッド |
| 相手構成 | [第1世代の設定](../records/generation-001-config.json) |

当時の設定JSONには実行環境の絶対パスが含まれる。現在の環境で再実行する場合は [再現手順](../reproduction.md)に従ってパスを置き換える。実時間打切りとCPU負荷により、同じseedでも得点が一致するとは限らない。

## 実装上の探索時間

`HORIZON_SEARCH_MS` で探索上限を変更できる。未指定時の上限は車種選択100,000 ms、日別回答48,000 msで、いずれも要求時間の78%以下とする。
