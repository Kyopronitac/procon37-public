# solver01：第1世代

[一覧](../README.md) / [保存ソース](../solver01.rs) / [元の対戦サンプル](../../../../tester/game/samples/src/bin/game-sample-2.rs) / [世代記録](../records/generation-001.md)

第1世代で独立に設計したソルバ。区間ごとの経路、移動補給、焼きなましと車両別ビームを組み合わせ、翌日に残す燃料も評価する。ソースは現在の対戦相手slot2にあり、コミット `11d1e19` に保存されている。専用の経路先読みモジュールは `tester/game/samples/src/pool-generation-001/horizon.rs`。

正式評価run `1790521499134996039-41850` は30件すべて5体AC。順位合計は対象52、相手90・126・74・90で単独首位。対象得点合計は種類542・日別種類3586・玉数7245。短縮確認や候補1〜4の未達経緯は世代記録に残す。

この説明は当時の開発記録と保存した実装に基づく。

単一ファイル版は [solver01.rs](../solver01.rs)。元の入口は [entry.rs](entry.rs)、依存モジュールもこのディレクトリに無改変で保存した。

詳細資料：[アルゴリズム](algorithm.md) / [実行設定](settings.md) / [検証記録](validation.md)。
