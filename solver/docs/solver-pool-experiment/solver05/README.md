# solver05：第5世代

[一覧](../README.md) / [単一ファイル版](../solver05.rs) / [元の分割ソース](main.rs) / [世代記録](../records/generation-005.md)

第5世代で独立に設計した現行対象ソルバ。`main.rs` がJSON Linesの入出力を担当し、`solver/network.rs` が道路経路、`solver/search.rs` が車種選択と日別計画を担当する。4台の当日経路候補に燃料余裕のある第4経路を追加した候補8が昇格した。選択時の経路候補数は3のまま。保存ソースは現行対象の3ファイルを無改変で複製した。

正式評価run `1790658701286043764-3` は30件すべて5体AC。順位合計は対象68、相手96・122・69・75で単独首位。対象得点合計は種類542・日別種類3588・玉数7417。候補1〜7は単独首位に届かず、候補8で昇格した。保存バイナリのSHA-256は世代記録を参照。

第5世代の完成時点で育成を終了した。ソースのスナップショットは以後の開発用ファイルと独立して保存する。

単一ファイルの [solver05.rs](../solver05.rs) は、この3ファイルのモジュールをインライン化した記録である。

詳細資料：[アルゴリズム](algorithm.md) / [実行設定](settings.md) / [検証記録](validation.md)。
