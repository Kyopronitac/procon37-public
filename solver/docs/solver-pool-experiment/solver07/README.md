# solver07：第7世代

公開通信仕様と共通エンジンから新規設計した正式昇格版v37です。店舗と補給地点の訪問列を焼きなましとビーム探索で改善し、小盤面では翌日の種類数も確認します。 従来のsolver-pool方式による独立した新規開発・評価・昇格の世代です。`main.rs` がJSON Linesの入出力を、`solver/planner.rs` が探索と提出前の検証を担当します。

正式評価run `1791198519955245014-18519` は30件すべて5体AC、警告0。対象の順位合計は65、平均順位は2.166667位で単独首位でした。対象の種類・日別種類・玉数の合計は543/3676/8419です。詳細は [検証記録](validation.md) に記載しています。

昇格コミット `da1c7888e251b84689059b61569ec8040809b177` から元の2ファイルを変更せず保存しました。単一ファイルの [solver07.rs](../solver07.rs) は、この2ファイルのモジュールをインライン化し、Rustfmtで整形した記録です。Cargoのビルド対象は `pool-solver-07`。出典・SHA-256・変換内容は [ソース対応表](../source-manifest.json) を参照してください。

保存形式の整理では追加ビルド・追加テストを行っていません。成績は保存元の評価によるものです。
