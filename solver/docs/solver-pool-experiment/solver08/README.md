# solver08：第8世代

[一覧](../README.md) / [単一ファイル版](../solver08.rs) / [元の分割ソース](main.rs) / [世代記録](../records/generation-008.md)

**従来のsolver-pool方式でゼロから新規開発した世代ではありません。** 第7世代を継続改善した候補のうち、既定フル30件で最良記録と同率の現採用v117を、ユーザー指示により第8世代として登録しました。

評価済みの [main.rs](main.rs) と [solver/planner.rs](solver/planner.rs) を変更せず保存しています。単一ファイルの [solver08.rs](../solver08.rs) は、この2ファイルのモジュールをインライン化し、Rustfmtで整形した記録です。独立ワークスペースの `pool-solver-08` はこの単一ファイル版をビルドします。診断ログの既存の世代識別子も維持しています。ソースの対応とSHA-256は [source-manifest.json](../source-manifest.json) を参照してください。

最良の観測記録は平均1.433333位・1位24/30件です。改善開始時の平均2.233333位・1位14/30件に対し、公式比較は19勝3同点8敗、日別種類+2・玉数+87でした。平均1.00位の目標は未達であり、実行環境による成績の変動もあります。

詳細資料：[アルゴリズム](algorithm.md) / [実行設定](settings.md) / [検証記録](validation.md)。

登録では保存元の通常テスト3件・既定フル30件とソースのハッシュ一致を確認し、追加ビルド・追加テストは行っていません。元の第1〜7世代の実装と記録は保持しています。単一ファイル版への整理でも追加ビルド・追加テストは行っていません。
