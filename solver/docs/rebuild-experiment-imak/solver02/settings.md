# 実行設定

再構築1（`cbeaafd`）の資料。記録ソース: [solver02.rs](../solver02.rs)。
[比較対象のアルゴリズム](../algorithms.md#solver02)。

本文中の旧ファイル名は、単一ファイル内の同名モジュールを示す。当時のアルゴリズム・設定・検証記録を保存し、参照先と実行コマンドを現在の配置へ更新した。
検証の数値・実行ファイルのハッシュ・「現在」などの記述は原コミット時点の記録であり、今回の単一ファイル化後に再計測した性能値ではない。

実行例を使う前に `cargo build --release --manifest-path solver/docs/rebuild-experiment-imak/Cargo.toml --target-dir target --bin solver-02` で対象版をビルドする。

| 指定 | 内容 |
| --- | --- |
| 第1引数 | 探索乱数seed。省略時0。問題の生成seedとは別 |
| `SOLVER_BUDGET_MS` | 動作確認用の探索時間。タイプ選択・各日へ適用。本番の比較では設定しない |
| `SOLVER_LOOKAHEAD=1` | 実験用の2日先読みを有効にする。既定では無効 |

通常は要求の `timeLimitMs` から1.5秒を引いた時間まで計算する。
テスタの既定ではタイプ選択60／90／120秒、各日60秒なので、探索予算は58.5／88.5／118.5秒と58.5秒になる。
短縮指定も受信した期限以内に制限する。

ソルバは1プロセス・1スレッド。並列テストは `--jobs` でケース数を指定する。
標準出力には回答JSONだけを出し、時間・探索回数・選択した車種などの診断を標準エラーに出す。
