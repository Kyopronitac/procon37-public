玉数は9減りました。一方、公開得点の優先順である種類数・日別種類数・玉数では日別種類数が1増えており、平均順位も0.2改善しています。各ケースでは14敗あり、全ケースの改善を意味しません。日別種類数はseed 0・1・27で各1増え、16・24で各1減りました。
