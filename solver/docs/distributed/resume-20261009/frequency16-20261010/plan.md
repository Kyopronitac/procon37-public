# 16×16試合向け共有頻度の比較と配置

2026年10月10日04:52 JST開始。ユーザーの試合準備を優先し、6:00締切から06:15までの延長を相談して了承された。新しい2案だけを16×16のseed0・3・6・9で公式時間（車種選択60秒・各日60秒）評価する。4件は32分20秒、2案合計64分40秒。結果確認、選定、VOID3台へのデプロイ、commit・pushまでを延長期限内に実施する。

比較対象はC013（共有周期500ms）と、C014（100ms）、C015（2000ms）。追加候補はELITE_INTERVALだけを変更し、受信側確認250ms、停滞条件、探索、提出、スレッド割当は維持する。この定数はネット送信とローカル公開の両方、および共有に必要な残時間判定で共用される。単純なTCPパケット数だけの変更ではない。

基準はユーザー指定に従い保存済み4件を再利用する。seed0はC012、seed3・6・9はC013であることを明記済み。基準の分散平均順位1.50、種類数48・日別種類数334・玉数637、並列相手も同じ。条件が完全に揃った新規3案評価ではなく、試合向けの限定比較とする。正式12件評価済みの一般採用版D0とは区別する。
