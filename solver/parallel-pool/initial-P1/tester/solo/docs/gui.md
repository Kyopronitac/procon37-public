## 実行して再生する

1. GUIを開き、右上の「新しく実行」を押す。
2. 実行名、seed数または単一seed、形式、ソルバ内並列の有無を指定する。
3. 必要なら詳細設定で同時seed数・ビルド・ソルバコマンド・時間制限を変更する。
4. 実行すると、進捗と結果が自動保存される。
5. 結果一覧で各ケースの「再生」を押す。

既定は60seed・形式自動決定・ソルバ内並列なし。設定項目の意味はCUIと共通。

- 実行設定の各項目 → [usage.md](usage.md)

| 画面・操作 | 役割 |
| --- | --- |
| 左側の履歴 | 保存済み実行を選ぶ。初回は直近の実行を開く |
| 「この設定で再実行」 | 過去の設定をコピーして編集し、別の実行として保存 |
| 実行中の進捗 | 過去の履歴を閲覧した後、実行中の結果へ戻る |
| ブラウザの戻る／進む | 結果・比較・リプレイ・プレビュー間を移動 |

履歴やリプレイの閲覧では、新規実行の入力を上書きしない。設定は実行ごとの `run.json` に保存する。次回サーバー起動時の既定設定には `--config` を使う。

## 結果を絞り込む

| 項目 | 選べる内容 |
| --- | --- |
| 絞り込み | 形式・判定・seed |
| 並び順 | seed順、得点順、問題のあるケースを先にする順 |
| 得点順の優先順位 | ACを先にし、種類数 → 日別種類数 → 玉数 → 回答時間 |
| 判定 | AC・WA・TLE・RE・CE |

- 判定の意味と優先順 → [usage.md](usage.md#結果と判定を読む)

一覧の条件や比較・再生の表示状態はURLにも反映され、再読み込みやURLからの直接表示に対応する。

## リプレイを操作する

| 操作 | 方法 |
| --- | --- |
| 再生・停止、速度変更 | 再生バーの操作ボタン |
| 特定の時点へ移動 | 再生バーをクリック／ドラッグ |
| 日の先頭へ移動 | 日付ボタン |
| 1フレームずつ移動 | キーボードの左右キー |
| 別のケースへ移動 | 「前のseed」「次のseed」。一覧の絞り込み・並び順に従う |
| 一覧へ戻る | 「一覧へ」。絞り込み条件を保持 |
| 詳細を見る | 「詳細」からスコア・車・出来事・設定のタブを選ぶ |

再生バーは日ごとに区切られ、長さは日別ステップ数に対応する。バーにマウスを重ねると移動先の日・ステップを確認できる。 車両は移動に必要なステップ数に合わせてセル間を滑らかに移動する。アニメーションは再生速度に追従し、停止するとその位置で止まる。日付を切り替えたときは、その日の配置へ移る。

### 盤面の表示

[非公式練習場の試合ページ](https://procon37arena.online/arena/matches/951)の盤面と同じ座標・色・記号・寸法を使う。周囲の画面は従来の成績カード・再生操作・詳細タブの構成。盤面描画は `common/web/board.js`、ズーム・ドラッグ操作は `common/web/viewer.js` にあり、単独・対戦テスタと対戦サーバーで共通。

| 表示 | 意味 |
| --- | --- |
| 地形 | 茶が平地、山の記号付きの深緑が山地、波の記号付きの青が池 |
| 道路の外枠 | 当日の道路状態。道路の内部は灰で、黄の枠が混雑、赤の枠が渋滞。日中は固定。ヒートマップには枠線を表示しない |
| 店舗の色とうどん記号、横の番号 | 系列。参照ページと同じ10色を循環するため、系列番号も併記して識別する |
| 店舗下の点 | 金色が残り在庫、薄い白が売れた分 |
| 薄く表示した店舗 | 在庫切れ |
| 金色の輪 | そのステップにうどんを獲得した店舗 |
| 円い車 | 巡回車。チームの色で表示し、下のバーは残り燃料。50%以下で黄、25%以下で赤 |
| 給油の滴がある角丸の四角 | 補給車。参照ページと同じチームの色 |
| 緑の輪 | そのステップに燃料を補給された車 |
| 同一セルの車 | 小さな円周上に並べて表示 |
| 黄色の枠 | 選択中のセル・車 |
| 点線 | 全巡回車・補給車の当日全体の移動経路。チーム色を基に車両ごとに色相を変える。日付が変わると更新 |
| 車の選択 | 位置・燃料・移動予約を確認 |
| セル・出来事の詳細 | 獲得、補給、不正回答の理由などを確認 |

点線は参照座標で線幅1.4・描画3 / 間隔4・不透明度0.65・丸い端を使う。経路は車を選択しなくても表示され、同じ日の間は再生ステップによらず同じ線を表示する。「設定」の「全車両の当日の経路を表示（点線）」で表示を切り替えられる。

対戦の成績カードは表示ステップの得点と最終順位を表示する。カードまたは選択欄で、そのチームの在庫・車両・スコアに切り替える。

盤面右下の「＋」「−」で100〜600%に拡大・縮小でき、「⟲」で初期表示へ戻る。拡大中はドラッグで移動でき、ズーム後もセルをクリックして詳細を確認できる。「詳細」を開くとスコア・車・出来事・表示設定を確認でき、狭い画面では盤面に重ねて表示する。GIFはズームにかかわらず盤面全体を出力する。

リプレイ中は履歴サイドバーを隠し、盤面・成績カード・再生操作・詳細を画面内に収める。日程や問題全体は「問題JSON」でも確認できる。

### 滞在時間のヒートマップ

盤面上部の「ヒートマップ」で表示を切り替える。既定の「巡回車＋補給車（合計）」では、各セルの両車種の延べ滞在ステップ数を合算し、セル全体を青の濃淡で表示する。セル内の数字と枠線は表示しない。対数スケールで滞在時間が長いセルほど濃くなり、凡例は合計の最大値を示す。車種別にも切り替えられ、巡回車は青、補給車はオレンジで表示する。

- 色の濃さは `log(1 + 滞在ステップ数) / log(1 + 最大滞在ステップ数)` で正規化する。少ない滞在の差も見分けやすく、未訪問セルと全セル0の場合も扱える。数値の集計とクリック時の内訳は実際のステップ数を使う。
- ヒートマップではセル・道路・選択セルの枠線を表示せず、隣接セルの塗りつぶしをつなげる。通常盤面では道路状況を外枠で表示する。
- 「範囲」で当日と全日合計を選ぶ。当日の集計は再生ステップに依存せず、その日全体を表示し、日付が変わると更新する。
- 対戦では「対象」で選択チームと全チームを選ぶ。全チームの集計は車両の重ね表示の設定によらず全員を含む。
- 複数車両が同じセルにいる場合は滞在時間を合算する。巡回車1台と補給車1台が3ステップ滞在すると、合計は6ステップとなる。移動中は判定上の出発セルに計上する。
- セルをクリックすると、合計と巡回車・補給車それぞれの正確なステップ数を盤面下に表示する。未訪問セルは0、進入不可の池は地形表示を保つ。
- 表示状態はURLとブラウザの戻る／進むに保存される。「ヒートマップ」をもう一度押すと通常盤面へ戻る。

## GIFを保存する

1. リプレイで「GIF出力」を押す。
2. 対象日・速度・幅を選び、「GIFを作成」を押す。
3. プレビューを確認して「GIFを保存」を押す。

| 設定 | 選択肢 | 既定 |
| --- | --- | --- |
| 対象 | 全日／表示中の日 | 全日 |
| 速度 | 1／2／4／8／16倍 | 8倍 |
| 幅 | 480／640／960px | 640px |

- GIFには盤面・日・ステップ・スコアを含む。セル番号や車の経路は現在の表示設定を反映する。
- 高速再生ではコマを間引くが、各日の先頭と末尾は残す。最後のコマは0.6秒表示する。
- 作成中は進捗を表示し、「閉じる・中止」またはEscで中断できる。画面の再生位置は動かない。
- 64 MiBを超える場合は停止する。幅を小さくする、速度を上げる、表示中の日だけにする、のいずれかで再作成する。
- 処理はブラウザ内で完結し、外部サービスへの送信や追加ソフトは不要。

## 問題プレビュー・JSONを開く

| 操作 | 表示するもの | 履歴への追加 |
| --- | --- | --- |
| 「問題を生成して見る」 | 指定したseed・形式の盤面。ソルバは実行しない | なし |
| 「JSONファイルを開く」で問題JSONを選択 | 盤面のみ | なし |
| 同じ操作でリプレイJSONを選択 | 保存済みの試合。ソルバは再実行しない | なし |
| 履歴ZIPをインポート | 実行全体の問題・リプレイ・ログ | あり |

外部JSONはタブのメモリに保持する。戻る／進むでは復元できるが、ページを再読み込みした場合は開き直す。公式の複数プレイヤー問題も配置を閲覧できる。実行対象は1プレイヤーの生成問題。

表示中の出所は画面上部に示す。記録を切り替えると、前のケースとログを解除する。「リプレイJSON」「問題JSON」は表示中の保存記録をダウンロードする操作。
