## PR #9：ビルド省略時の比較識別の修正

2026-09-25、同じ相手を使う通常ビルドの履歴と `--no-build` の履歴が、ビルド設定の差だけで比較対象外になる指摘を回帰テストで再現した。

- 追加した比較の回帰テストは修正前に `different` で失敗し、修正後に `matched` で成功。

- `cargo clippy --offline -p procon37-common -p game --all-targets -- -D warnings`：成功。
