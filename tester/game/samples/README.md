# 対戦用サンプル

5人対戦テスタのプレイヤー1〜4に使うRustソルバ。各実装は `src/bin` の入口と独立した専用モジュールで、4個の独立プロセスとして動く。Cargo依存（`tester`、`serde`、`serde_json`）は必要。

| プレイヤー | 実行ファイル | ソルバ | 取得元 |
| --- | --- | --- | --- |
| 1 | `game-sample-1` | pool第2世代の昇格ソルバ | 正式run 1790551749037999892-54402 |
| 2 | `game-sample-2` | pool第1世代の昇格ソルバ | 正式run 1790521499134996039-41850 |
| 3 | `game-sample-3` | 第3世代ソルバ | 世代開発の採用候補2 |
| 4 | `game-sample-4` | pool第3世代の昇格ソルバ | 正式run 1790563781811011480-62511 |

sample1はpool第2世代を `src/pool-generation-002/` の専用モジュールとともに保存した独立コピー。sample2は `src/pool-generation-001/` の専用モジュールを持つ独立コピー。sample3〜4も独立コピーで、対象の `main.rs` や `solver/` を参照しない。元の入口と探索モジュールとの一致を整形後に確認している。取得コミットまたは採用実行ID、元ファイルのSHA-256、調整内容は [source-manifest.json](source-manifest.json) に記録する。世代開発の評価は [検証記録](../../../solver/docs/generation-development.md) を参照。

```sh
cargo build --release -p game-samples
cargo run --release -p game -- run 60 --label 'サンプル置換後・フル60件' -- 0
```

第1引数に整数seed（省略時0）を指定できる。時間制探索のため、同じ入力とseedでも実行負荷により回答が変わり得る。標準設定のバージョンは取得元コミットまたは採用実行ID・ソルバ名・調整版を含む。実行条件は各対戦履歴へ保存される。

対象ソルバの開発・評価では内部の閲覧・検索・Git履歴調査・逆解析を禁止する。ビルド・実行・成績・リプレイは確認できる。[規則](AGENTS.md) に従い、リポジトリ全体を検索する場合もサンプル実装を除外する。これは指示による運用上の制約であり、アクセスを遮断するものではない。強制的な保護が必要な場合は、開発側からソースにアクセスできない環境へ分離する。

sample4は `src/pool-generation-003/` の専用モジュールを持つ独立コピー。
