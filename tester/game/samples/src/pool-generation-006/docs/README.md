# 単一スレッドソルバ

公開通信仕様と共通エンジンの規則から実装した第6世代のソルバです。内部は単一スレッドで動作します。

移動時間と燃料を考慮した経路候補を使い、巡回車の訪問順と補給車の合流予定を探索します。焼きなまし、巡回の再構築、車両ごとのビーム探索を組み合わせ、提出前に共通エンジンで計画を検証します。

```sh
cargo build --release -p solver
target/release/solver 0
```

JSON Linesの通信入口はルートの `main.rs`、探索本体は `solver/planner.rs` です。
